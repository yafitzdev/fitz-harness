Architecture

Dependency graph generated from the real workspace:* references — layers are computed, not drawn by hand.
01
Desktop shell ≠ service

The Electron window is a client. Closing it never stops the host — runs, queueing, and engines keep working headlessly.

02
Engine adapters

NInfer, llama.cpp, OpenAI-compatible, and a deterministic fake all sit behind one adapter contract with a shared lifecycle.

03
Fitz-owned boundaries

The Pi SDK lives behind agent-core; SQLite behind storage; auth behind security. Nothing leaks across layers.

Conventions

  • Strict imports — every relative import uses the .js extension.
  • No shell-concatenated launches — engines start with executable + argv, never a joined string.
  • Secrets never surface — redaction is recursive and applies to logs, diagnostics, and exports.
  • One check command — pnpm check = typecheck + tests.
