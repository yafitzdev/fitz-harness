# 整合设计与验证

## 目标

把三个上游能力合并为一个可安装、可调优、符合 DSH 官方 agent-preset 机制的包：

1. 外部路由选择稳定行为带：`spec / react / weak`。
2. J-Space 选择运行协议：`fast / full / loop`，并给出按需模块。
3. oh-we-need 把 DeepSeek V4 CoT 塑造成“每步一个动作、第一人称、先分类后执行”。

## 工作机制

### 1. 静态系统段

`router-jspace.mjs` 在 `system-prompt/assemble` 中追加一个固定 `cognition-protocol` section。它是静态文本，不随任务变化，因此不会破坏 DSH 前缀缓存。

内容包含：
- 三寄存器：inner / ledger / outer。
- J-Space 门控：fast / full / loop。
- `✓ / ? / ✗` 内部标记与可展开规则。
- oh-we-need 的 `we need to ...` 与 modal verb 风格。
- 交付前 goal 逐行核对与未检查边界声明。

### 2. 外部路由

首次请求前捕获真实用户消息，用 `router-core.mjs` 的分类逻辑决定：
- `react`：build/创建类任务，写优先工具面。
- `spec`：fix/维护类任务，读优先工具面。
- `weak`：无明确关键词的任务，由模型内路由，使用 RL 形工具面。
- 首个持久 `tool/call` 后恢复完整 Standard 工具目录。

### 3. J-Space pass / module 路由

在同一个组装与 near-field 引导中计算：
- `loop`：长程、多文件、多轮、仓库级任务。
- `full`：多步但单交付物、分析/实现/修复类任务。
- `fast`：单步或一眼可核验任务。
- 模块选择：
  - loop：`capacity / broadcast / markers / self-monitoring`
  - fix：`introspection / markers`
  - build：`directed-focus / empirics`
  - 默认：`deep-reasoning / self-monitoring`

### 4. near-field 引导

每条真实用户消息后，`session/event` 监听器向 `agent.inbox.append` 追加一条引导。它不属于 system 前缀，因此动态内容不会清缓存。

- 第 1-2 轮：分类 + pass + modules。
- 第 3 轮起：强制“这是新任务，重新分类”。
- 简单任务：一个具体动作后产出。
- 复杂任务：有向深度思考；Pro 模型追加决策闭环。
- 引导文本使用 `we need ... / I will ...`，落实 oh-we-need。

### 5. 账本持久化

`cog_ledger` 工具把 J-Space 五段账本写入 `$DSH_HOME/cognition-ledger/<session>.json`：

```text
Goal / Core / Verified / Open / Next
```

支持 `update / read / ship / clear`。`ship` 返回逐行 goal 核对指令，替代 J-Space 的 Python `ship`。

### 6. 与已装插件的共存

- 本机已装配 `dsh-mode-boost`。
- 本 preset 注册 `router-persona` section 与 `dev_router_status` 工具，mode-boost 的共存守卫会识别并整体 no-op。
- 本 preset 不替换 super-injector，不触碰 `cordis.patch.yml`。
- 若与 router-standard 同机并存，各自是独立 preset，新会话二选一，不会同时注入。

## 安装

```powershell
cd integrated-preset/router-jspace
.\scripts\install.ps1
```

脚本会：
1. 把 `router-jspace` 复制到 `$DSH_HOME/.agent-presets/router-jspace`。
2. 把 `j-space` 与 `oh-we-need` 复制到 `$DSH_HOME/skills/`。
3. 提示重启 DSH，并在新会话选择 `Router J-Space (experimental)`。

注意：agent-preset 只在会话创建时组装，已有会话不能热切换。
